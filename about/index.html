About Stock Agent News
#

Stock Agent News is a fully automated AI-powered stock market analysis platform. Every morning (07:00 KST), the system collects news, writes a single English daily brief, attaches a cover image and optional audio, and publishes to GitHub Pages — with no manual editing step.

How It Works
#

  1. Data collection — RSS feeds from three sources (~25–30 articles/day).
  2. AI analysis — A local LLM (Ollama + Gemma 3 12B QAT) synthesizes one comprehensive market brief (~1,000–1,500 words).
  3. Cover image — A random thumbnail from an article that includes an image (RSS media fields or article page); saved with source attribution.
  4. Audio brief — Gemini TTS (Google AI Studio) reads the English brief aloud; one WAV file per day with an in-page player.
  5. Earnings calendar — yfinance scans all S&P 500 tickers on Yahoo Finance for the next 7 days; listed after Today’s Takeaway with quote, estimates, and company links.
  6. Vocabulary tooltips — Key finance terms are wrapped with the Hugo voca shortcode (pronunciation + bilingual example on hover); the dictionary grows daily via Ollama suggest + auto-review (2e_vocab_suggest.py).
  7. Deploy — Hugo builds the static site and pushes to GitHub Pages.

Retired: Pollinations.ai
#

Through early June 2026, cover images were generated via Pollinations.ai (FLUX). The public endpoint began returning HTTP 402 when paid Pollen credits became required. The pipeline now uses RSS-sourced images instead — no image-gen API.

S&P 500 earnings (yfinance)
#

Each daily brief includes an Upcoming S&P 500 Earnings section after Today’s Takeaway. The pipeline scans all ~500 S&P constituents via yfinance (Ticker.calendar) and filters to the next 7 days. Each row links to the Yahoo Finance quote, an earnings estimates page, and the company website when available. Constituents list comes from a public S&P 500 CSV (cached 24 h). No API key required.

Previously FMP was used, but the free tier returned only a handful of rows per request and omitted major names (e.g. Broadcom on dates when it was in-window).
